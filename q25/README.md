# Q25 - Traffic Signal Lights

## Problem Statement
Create Responsive website for showing Traffic signal lights. Use appropriate diagrams and glowing LEDs within HTML code.

## Features
- Three LED lights (Red, Yellow, Green)
- Glowing effect when active
- Manual control buttons
- Auto mode (cycles through lights)
- Stop button
- Status display
- Responsive design

## How to Use

1. **Open in Browser**
   ```
   Open index.html in any browser
   ```

2. **Manual Control**
   - Click "Red" for red light (STOP)
   - Click "Yellow" for yellow light (READY)
   - Click "Green" for green light (GO)

3. **Auto Mode**
   - Click "Auto Mode" to cycle through lights automatically
   - Changes every 3 seconds
   - Click "Stop" to stop auto mode

## Light Meanings
- 🔴 **Red**: STOP
- 🟡 **Yellow**: READY
- 🟢 **Green**: GO

## Technologies
- HTML5
- CSS3 (box-shadow for glow effect)
- JavaScript
- setInterval for auto mode
- Responsive design

## Features
- Realistic LED glow effect
- Smooth transitions
- Dark signal box
- Status text display
- Auto cycling mode
