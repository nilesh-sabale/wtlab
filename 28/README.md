# Lab 28 - Theme Toggle App

A React application that allows users to toggle between Light Mode and Dark Mode using React Hooks.

## Features
- Toggle button for theme switching
- useState() to manage theme state
- Dynamic background and text colors
- Display current theme mode
- Theme persists during component re-render

## Setup with Vite

1. Navigate to the lab folder:
```bash
cd 28
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open browser at the URL shown (usually http://localhost:5173)

## Build for Production

```bash
npm run build
```

The build output will be in the `dist` folder.

## Technologies
- React 18
- Vite (Fast build tool)
- React Hooks (useState)
- CSS transitions
