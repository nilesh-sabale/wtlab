# Lab 29 - Digital Clock App

A React application that displays a real-time digital clock which updates every second using React Hooks.

## Features
- Real-time clock display in HH:MM:SS format
- useState() to store current time
- useEffect() to update time every second
- Start/Stop clock functionality
- Display current date

## Setup with Vite

1. Navigate to the lab folder:
```bash
cd 29
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open browser at the URL shown (usually http://localhost:5173)

## Build for Production

```bash
npm run build
```

The build output will be in the `dist` folder.

## Technologies
- React 18
- Vite (Fast build tool)
- React Hooks (useState, useEffect)
- setInterval for time updates
