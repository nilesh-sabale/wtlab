# Q22 - Canvas Drawing

## Problem Statement
Create a responsive HTML document with canvas tag. Write JavaScript code which takes the mouse click event for the point and draws any shape like line and rectangle.

## Features
- Canvas for drawing
- Draw lines by clicking two points
- Draw rectangles by clicking two points
- Switch between line and rectangle mode
- Clear canvas button
- Responsive design

## How to Use

1. **Open in Browser**
   ```
   Open index.html in any browser
   ```

2. **Draw Line**
   - Click "Draw Line" button
   - Click two points on canvas
   - Line will be drawn

3. **Draw Rectangle**
   - Click "Draw Rectangle" button
   - Click two points on canvas
   - Rectangle will be drawn

4. **Clear**
   - Click "Clear Canvas" to reset

## Technologies
- HTML5 Canvas
- JavaScript
- Mouse click events
- Canvas 2D context

## Features
- Click-based drawing
- Visual feedback (red dots for points)
- Mode switching
- Clear functionality
