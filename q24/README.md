# Q24 - Age Calculator

## Problem Statement
Write JavaScript code to accept birth date and calculate age in year, month and date format.

## Features
- Date input for birth date
- Calculate age in years, months, and days
- Accurate calculation considering leap years
- Clean, user-friendly interface
- Responsive design

## How to Use

1. **Open in Browser**
   ```
   Open index.html in any browser
   ```

2. **Calculate Age**
   - Select your birth date from date picker
   - Click "Calculate Age" button
   - See your age in years, months, and days

## Calculation Logic
- Calculates years, months, and days separately
- Handles negative days by borrowing from previous month
- Handles negative months by borrowing from previous year
- Accurate for all dates

## Technologies
- HTML5 Date Input
- JavaScript Date object
- DOM manipulation
- Responsive CSS

## Example Output
```
25 Years
3 Months
15 Days

You are 25 years, 3 months, and 15 days old!
```
