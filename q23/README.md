# Q23 - Style Switcher with jQuery

## Problem Statement
Write HTML JavaScript (jQuery) code for applying one style throughout all controls using one of three buttons. Each button is causing separate style for the entire page.

## Features
- Three style themes (Blue, Dark, Green)
- jQuery for style manipulation
- Applies style to all controls
- Smooth transitions
- Responsive design

## Themes

1. **Blue Theme**
   - Blue gradient background
   - White container
   - Blue buttons and borders

2. **Dark Theme**
   - Dark background
   - Orange accents
   - Dark inputs

3. **Green Theme**
   - Green gradient background
   - Light green container
   - Green buttons and borders

## How to Use

1. **Open in Browser**
   ```
   Open index.html in any browser
   ```

2. **Switch Themes**
   - Click "Blue Theme" for blue style
   - Click "Dark Theme" for dark style
   - Click "Green Theme" for green style

## Technologies
- HTML5
- jQuery 3.6.0
- CSS3 transitions
- Dynamic styling

## jQuery Features
- `.css()` method for styling
- Event handlers
- DOM manipulation
- Smooth transitions
