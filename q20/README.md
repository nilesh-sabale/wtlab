# Q20 - Tic-Tac-Toe Game

## Problem Statement
Write PHP code for Tic-Tac-Toe Game.

## Features
- Two player game (X and O)
- Click on cell to make move
- Automatic turn switching
- Winner detection
- Draw detection
- New Game button
- Session-based game state

## How to Run

1. **Access Game**
   ```
   http://localhost/q20/
   ```

2. **How to Play**
   - Player X starts first
   - Click on empty cell to place your mark
   - Players alternate turns
   - First to get 3 in a row wins
   - Click "New Game" to restart

## Winning Conditions
- 3 in a row (horizontal)
- 3 in a column (vertical)
- 3 in diagonal

## Technologies
- PHP
- Sessions (for game state)
- CSS Grid (for board layout)
- Responsive design
